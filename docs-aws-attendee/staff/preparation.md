# 講習会側の事前準備

受講者の実習を始める前に、環境構築担当者が環境を構築し、講師が教材を配布します。左の「講習会側の準備」から工程ごとのページを開けます。

運用・構築コマンドは **ai-learning-handson-aws-infra の作業環境**で実行します。受講者のPCやLeRobotDocsで実行するコマンドと区別してください。

## 進める順番

| 順番 | 工程 | 担当 |
| --- | --- | --- |
| 1 | [開始条件と道具](preparation/environment-start.md) | 環境構築担当者 |
| 2 | [開催設定とAMIの選定](preparation/event-settings.md) | 環境構築担当者 |
| 3 | [導入済みAMIの確認](preparation/ami-find.md) | 環境構築担当者 |
| 4 | [一時インスタンスの起動](preparation/ami-launch.md) | 環境構築担当者 |

教材配布を済ませたら、[受講者のPCの準備](../setup.md)へ進み、以降の共通ページで受講者の操作と担当者の操作を同じ順番で確認します。
