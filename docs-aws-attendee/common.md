全ページのヘッダーにある「各種値の設定」ボタンからも、同じフォームをモーダルで開けます。ページを移動せず編集でき、このページのフォームとも同期します。閉じるボタンまたは Escape で戻ります。閉じても入力した有効な値は保存されます。

## 入力と保存の使い方

- 入力した有効な値は、このブラウザのこの役割用に保存されます。ページを移動しても引き継がれ、入力と保存をリセットすると空欄へ戻ります。
- 受講者・講師・環境構築担当者はそれぞれ独立した保存領域です。既存の LeRobot の値設定にも影響しません。ホスト名やポートが違うURLではブラウザの保存領域も異なります。
- パスは引用符を付けず入力します。空白やアポストロフィはそのままで構いません。`~` は使わずホームディレクトリの絶対パスにしてください。コマンド引数の引用符は自動で付きます。
- 認証情報の本文、アクセスキー、パスワード、期限付きURLは入力しないでください。そのための保存欄はありません。認証ファイル名・期限付きURLなどの手動指定項目は各手順で置き換えます。
- 未設定・形式不正・手動指定の項目が残る場合も、「コピー」で現在表示中の内容をコピーできます。未設定表示や山括弧の項目はエディタで置き換えてから実行してください。注意書き自体はコピーに含みません。
- 入力は端末の環境変数を設定しません。`$AWS_PROFILE` 等のシェル変数は書き換えず、実行場所やログイン条件は各手順に従います。

## 反映されるコマンド

以下は値の反映を確認するための表示です。実行する場合は手順ページの前提と実行場所を確認してください。

```bash
source ~/gclue-ai-handson/{{EVENT_ID}}/activate
gclue-ai-handson-attendee env info
```

EC2 のデータセット確認で使う値:

```bash
DATASET_DIR={{DATASET_DIR_SH}}
```

```text
https://s3.console.aws.amazon.com/s3/buckets/{{BUCKET}}?region={{REGION}}&prefix={{ATTENDEE_ID}}%2F&showversions=false
```

## 設定ファイルの受け渡し

「エクスポート」でバージョン付きの共通JSONを保存し、別の役割の「インポート」で読み込みます。モーダルとこのページのどちらからも使えます。許可された有効な項目だけを採用し、読み込んだ値を同名の設定へ反映します。ファイルにない項目・不正な項目は既存値を維持します。採用・無視した項目名は結果に表示されます。

この役割のフォームにない、他の役割用の有効な項目も保存して再エクスポートできます。知らない項目名や不正値は保存しません。認証情報を渡す形式ではありません。「入力と保存をリセット」は、他の役割用に保持した値も含め、この役割の保存領域を空にします。

## 本文にも反映される値

📝は値を入力する対象の目印です。未設定の状態でも設定後でも表示されます。手動置換が必要な項目にも目印が付き、その値は手順に従って置き換えます。「コピー」で取得するコマンドには目印は含まれません。
