# AWS 講習会・{% if audience == "staff" %}講習会側{% else %}受講者{% endif %}ガイド

最初に [共通値の設定](common.md) を開き、講師から受け取った値を入力してください。認証情報ファイルのパス・期限付き URL はフォームに保存せず、各コマンドの手動置換箇所で指定します。

手元の PC から自分用の EC2（クラウド上の Ubuntu）に接続し、LeRobot のデータセットを確認して、成果を手元に持ち帰るための手順です。AWS 資源の構築・削除は講師に任せ、受講者は配布された一時認証情報を使います。

この版は **2026-10-08〜09 の検証記録に基づく試験版** です。[出典と検証範囲](verification.md)に、実測済みと未検証の境界を記載しています。GPU 学習の成功や、講習会全体の終了・撤去の完了を保証する版ではありません。

!!! warning "開始前に講師と確認すること"
    macOS 対応修正 `fc6e58d` を含む受講者ツールが必要です。検証時点では旧配布版への更新は未実施でした。講師による修正版の公開と、コースに合わせた EC2・実習環境の準備が済んでから開始してください。

## 従来の LeRobot 実習と AWS を組み合わせて進める

[LeRobot 実習と AWS 連携の進め方](aws-workflow.md)では、手元の SO-101 で収集し、S3 経由で EC2 へ送り、学習したモデルを回収して手元で推論する流れを、従来と同じページ分け・章立てで進められます。配布データを使う場合の途中参加や、学習を行わない基本コースの進め方も記載しています。

## AWS 接続・データ確認を中心に進める

| 順番 | 作業 | 完了の目安 |
| --- | --- | --- |
| 1 | [PC の準備・導入・更新](setup.md) | `env info` に自分の開催・受講者 ID が出る |
| 2 | [コンソール・EC2・Git 接続](connect.md) | DCV のデスクトップ、SSH の ubuntu プロンプトが出る |
| 3 | [教材取得・データ表示・情報確認](dataset.md) | SHA 検証、Rerun の表示、info の件数を確認する |
| 4 | [成果保存と回収](save.md) | 再取得したファイルの内容が一致する |
| 5 | [終了時の片付け](finish.md) | 必要な成果を手元へ回収後、講習会用の認証情報などを削除する |

困ったときは [トラブルシューティング](troubleshooting.md) を開いてください。

## 実行場所と置換値

**手元** は Mac 等のターミナル、**EC2** は SSH 接続後や DCV デスクトップ内のターミナルです。ターミナルの場所を確認してから実行します。共通値は [設定フォーム](common.md) からコード例へ反映されます。残る `<…>` は手動で置き換える箇所です。認証ファイルは絶対パスを指定し、例の引用符は残してください。

| 表記 | 講師から受け取る値 |
| --- | --- |
| `{{EVENT_ID}}` / `{{ATTENDEE_ID}}` | 自分の開催と利用者の識別子 |
| `<認証情報ファイル>` | 配布された `.env` のパス。同時配布の `.credentials` は同じフォルダに置く |
| `<導入スクリプトの URL>` | 講師が配布する有効期限付き URL。資料には保存しない |
| `{{BUCKET}}` / `{{REGION}}` | S3 のバケット名と AWS リージョン |
| `{{DATASET_DIR}}` / `{{DATASET_REPO_ID}}` | EC2 上のデータセットの絶対パスと識別名 |

認証情報・鍵・期限付き URL を Git、画面共有のログ、チャットへ貼り付けないでください。
