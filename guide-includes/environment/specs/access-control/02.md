## 構成

### 主体

| 主体 | 名前 | 引き受け・利用の方法 | 用途 |
| --- | --- | --- | --- |
| 講師の認証情報 | 講師自身のもの（IAM Identity Center の権限セットなど） | 設定の `aws.profile`（または `--profile`） | 払出し専用ユーザーのアクセスキーを SSM パラメータから読むことだけ |
| 払出し専用ユーザー | `GClueAiHandsOn-{{EVENT_ID}}-Issuer`（IAM ユーザー、人ではない） | SSM パラメータ `/GClueAiHandsOn/{{EVENT_ID}}/IssuerAccessKey` のアクセスキー | 受講者の一時認証情報の発行、講師用ロールの引き受け、受講者単位の失効、受講者の EC2 への一時認証情報の書き込み |
| 受講者ロール | `GClueAiHandsOn-{{EVENT_ID}}-Attendee` | 払出し専用ユーザーが、受講者 ID と開催 ID のセッションタグ付きで引き受ける | 受講者に配る一時認証情報。自分の EC2 への接続と、自分のS3 バケットパス・`shared/` の利用 |
| 講師用ロール | `GClueAiHandsOn-{{EVENT_ID}}-Instructor` | 払出し専用ユーザーが引き受ける | 教材の公開、一斉配布、スナップショット、`shared/` への書き込み、導入スクリプトの期限付き URL の署名 |
| インスタンスロール | `GClueAiHandsOn-{{EVENT_ID}}-Instance` | 受講者の EC2 のインスタンスプロファイル | SSM の管理と `shared/` の読み取り |

運用ツールのコマンドと、使う主体の対応は次のとおりです（`commands/__init__.py`（元インフラリポジトリの参照資料） の `issuer_session`・`instructor_role_session`）。

| コマンド | 主体 |
| --- | --- |
| `credentials issue` / `send` / `revoke` | 払出し専用ユーザー |
| `release build` / `publish` / `promote` / `bootstrap-url`、`rollout ...` | 払出し専用ユーザーから引き受けた講師用ロール（セッション時間は `max_session_duration_seconds`） |
| 受講者用のコマンド（`connect`、`files`、{% if attendee_console_access %}`console-url`、{% endif %}受講者用ツール） | 受講者ロールの一時認証情報 |

### 払出し専用ユーザーとアクセスキー

- スタックが IAM ユーザーと、同名のカスタマー管理ポリシー（払出し担当用の権限）を作ります。
- アクセスキー（`AWS::IAM::AccessKey`）を作り、その ID とシークレットを JSON（`AccessKeyId`、`SecretAccessKey`）で SSM パラメータ `/GClueAiHandsOn/{{EVENT_ID}}/IssuerAccessKey` に置きます。
- パラメータは SecureString で、AWS 管理キー `aws/ssm` で暗号化します。
- CloudFormation は SecureString のパラメータを作れないため、カスタムリソース（`AwsCustomResource`、Lambda）が作成と更新で `ssm:PutParameter`（上書き可）を、削除で `ssm:DeleteParameter` を呼びます。
- カスタムリソースのログは値を伏せる設定（`Logging.with_data_hidden()`）にします。テンプレートにはシークレットの参照式だけが入ります。
- カスタムリソースの Lambda のロールには、このパラメータだけを対象にした `ssm:PutParameter`・`ssm:DeleteParameter` のインラインポリシーが付きます。
- ユーザー、アクセスキー、パラメータはスタックの削除で一緒に消えます。
