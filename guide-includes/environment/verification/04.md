## 同梱スクリプトの契約

[setup-lerobot-ec2.sh](<<= guide_link('staff/environment/scripts/setup-lerobot-ec2.sh') =>>) は上記 `ccfd1a3` の実ファイルを内容変更なしで転載しています。Ubuntu 24.04 x86_64 の `ubuntu` ユーザー向けで、sudo とインターネット接続が必要です。OS パッケージ、uv、AWS CLI、LeRobot の固定版を導入します。既存版や Git SHA、追跡ファイルの変更が合わない場合は停止します。

NVIDIA ドライバー、SSM、SSH、DCV の導入、AWS リソース作成、認証情報の払出し、データセット取得、学習は行いません。元の検証では構文、ヘルプ、隔離 mock 14 ケースが成功していますが、**スクリプト全体の EC2 実行は未検証**です。手動で同じ依存が導入できたことは、一括実行成功の証明ではありません。LeRobotDocs 側では構文とヘルプ、元ファイルとの一致を確認します。

インスタンスストア NVMe の利用は将来の検討項目です。この手順で自動フォーマットは行いません。
