## 3. 構築前に確かめる

### 3.1 設定ファイルを検査する

設定ファイルを読み込んで、AWS に作るものの定義を組み立てます。
アカウントは変更しません。
`SYNTH` に続けて `GClueAiHandsOn-{{EVENT_ID}}` と表示されれば成功です。

```bash
uv run gclue-ai-handson-cdk --env-dir {{CONFIG_DIR_SH}} synth
```

設定に誤りがあると、項目名を含むエラーが表示されます。
エラーの内容に従って設定ファイルを直してから、もう一度実行してください。

### 3.2 作られるものを確かめる

構築で作られるもの・変わるものの一覧を表示します。
アカウントは変更しません。

```bash
uv run gclue-ai-handson-cdk --env-dir {{CONFIG_DIR_SH}} diff
```

初回は、すべて新しく作られるもの（`[+]`）として表示されます。
