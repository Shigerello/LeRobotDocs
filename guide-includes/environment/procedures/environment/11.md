## 7. 撤去する {#7-撤去する}

最終成果回収と撤去は未完了で、以下は実行済みの報告ではありません。保持対象と担当者を確認してから実施します。

講習会の終了後に、次の順で行います。

1. **受講者の成果を回収する**

   EC2 のディスクは撤去で削除されます。
   受講者に、残したい成果を S3 へ保存してもらいます。
   必要なら、ディスクのスナップショットを取っておきます。

2. **配布用のスナップショットを削除する（講師）**

   講師が教材の配布のときに作ったスナップショットを、講師に削除してもらいます（[講師の手順](<<= guide_link('staff/environment/handoff.md') =>>) の `rollout cleanup-snapshots`）。

3. **受講者の認証情報をすべて失効させる（講師）**

   講師に、講習会全体の認証情報を失効させてもらいます（[講師の手順](<<= guide_link('staff/environment/handoff.md') =>>) の `credentials revoke --all`）。

4. **終了保護を外す**

   講習会の EC2 のインスタンス ID を表示します。

   ```bash
   aws ec2 describe-instances \
     --filters Name=tag:handson-deployment,Values={{EVENT_ID}} \
     --query 'Reservations[].Instances[].InstanceId' --output text
   ```

   表示されたインスタンス ID ごとに、終了保護を外します。

   ```bash
   aws ec2 modify-instance-attribute --instance-id {{INSTANCE_ID}} \
     --no-disable-api-termination
   ```

   `false` と表示されれば外れています。

   ```bash
   aws ec2 describe-instance-attribute --instance-id {{INSTANCE_ID}} \
     --attribute disableApiTermination \
     --query 'DisableApiTermination.Value' --output text
   ```

5. **環境を削除する**

   `--confirm-destroy` を付けて実行します（付けないと実行されません）。
   完了するまで画面には何も表示されません。

   ```bash
   uv run gclue-ai-handson-cdk --env-dir {{CONFIG_DIR_SH}} destroy \
     --confirm-destroy
   ```

   EC2、VPC、権限、払出し専用ユーザーと鍵のパラメータは、すべて削除されます。
   次のコマンドで `does not exist` と表示されれば、削除が終わっています。

   ```bash
   aws cloudformation describe-stacks \
     --stack-name GClueAiHandsOn-{{EVENT_ID}}
   ```

6. **バケットを削除する**

   S3 バケット `{{BUCKET}}` は、受講者の成果を守るため、5 の後も残ります。
   成果を回収し終えたら、AWS マネジメントコンソールの S3 の画面で、次の順に行います。
   この操作は元に戻せません。

   1. バケットを選んで「空にする」を実行する（古い版のファイルも含めて削除されます）
   2. バケットを選んで「削除」を実行する

   次のコマンドで `NoSuchBucket` または `Not Found` と表示されれば、削除が終わっています。

   ```bash
   aws s3api head-bucket --bucket {{BUCKET}}
   ```

7. **（任意）ログを削除する**

   払出し用の鍵を保存する処理のログ（鍵の値は含みません）が CloudWatch Logs に残ります。
   不要なら、表示されたロググループを削除します。

   ```bash
   aws logs describe-log-groups --log-group-name-prefix \
     /aws/lambda/GClueAiHandsOn-{{EVENT_ID}}- \
     --query 'logGroups[].logGroupName' --output text
   ```

   ```bash
   aws logs delete-log-group --log-group-name <ロググループ名>
   ```

8. **講師に与えた権限を外す**

   5.2 で講師に加えたポリシーを外します。
