## 用意するもの

- 講習会に使う AWS アカウント ID とリージョン
- 受講者 ID の一覧（例: `user01`、`user02`）
- 開催 ID（開催ごとに決める短い名前。英小文字で始まる英小文字・数字・ハイフンの 3〜16 文字。例: `fy26-spring`）
- 作業用の PC（macOS または Linux）と、インフラリポジトリの作業コピー
- 作業用の AWS の認証情報（AWS CLI の名前付きプロファイル）。必要な権限は 1.1 で管理者に依頼します。

開催 ID は、AWS に作るものの名前すべてに入ります。
撤去した後もバケットは残るため、同じ開催 ID を別の開催で使い回さないでください。
