## うまくいかないとき

| 表示・症状 | 原因と対処 |
| --- | --- |
| `払出し専用ユーザーのアクセスキーを SSM パラメータ ... から読めませんでした` | ログインが切れているか、プロファイル名が違います。手順 1.1・1.2 をやり直します。それでも出る場合は、講師のアカウントに読み出しの権限がないため、構築担当に伝えます |
| `注意: --duration-seconds ... は上限 ... を超えるため ... で発行します` | 上限で発行されています。これより長くはできないため、期限が切れたら発行し直します |
| `--duration-seconds は 900 以上で指定してください` | 900 秒以上を指定します |
| `設定ファイルの attendees にない受講者 ID です` | 受講者 ID の綴りを確かめます。受講者を増やす場合は構築担当に依頼します |
| `credentials send --ec2` で、インスタンスが見つからない・起動していないと表示される | その受講者の EC2 が止まっています。起動してから `--attendee` を付けて再実行します |
| `credentials send --ec2` で AWS CLI や Session Manager プラグインが見つからないと表示される | 講師の PC にインストールします |
| `credentials send --ssh-host` で `への書き込みに失敗しました` | [SSH 接続確認のコマンド](<<= guide_link('staff/instructor/operations.md#ssh-host-check') =>>)で、講師の PC からパスワードなしに入れるか確かめます |
| `版のディレクトリが既にあります（作り直すには --force）` | 公開前の版なら `release build` に `--force` を付けます。公開済みなら新しい版の識別子で作ります |
| `版 {{RELEASE}} は公開済みです。公開済みの版は変更せず、新しい版を作ってください` | 新しい版の識別子で作り直して公開します |
| `manifest がありません（先に release build を実行してください）` | `release build` を実行していないか、別のディレクトリで実行しています。リポジトリ直下で `release build` から実行します |
| `版 {{RELEASE}} は公開されていません` | `release publish --version {{RELEASE}}` を先に実行します |
| `公開済みの manifest の SHA-256 が指定値と一致しません` | 指定した SHA-256 が違うか、公開した版が意図したものと違います。`release build` の表示を確かめます |
| `対象外: {{ATTENDEE_ID}} <インスタンス ID>（状態 stopped、...）` | その EC2 には配られていません。起動して数分待ってから `--attendee {{ATTENDEE_ID}}` を付けて再実行します |
| `Run Command を送れるインスタンスがありません` | すべての EC2 が止まっているか、起動直後です。起動して数分待ってから再実行します |
| `事前確認に失敗した受講者があるため中止します` | 何も変更されていません。表示された `理由:` を確かめ、原因を取り除いてから再実行します |
| `試験の 1 台で失敗したため、残りへの適用を中止します` | 試験の 1 台以外は変更されていません。`理由:` を確かめ、教材を直した新しい版で配り直します |
| `理由: 他の収束処理が実行中です` | 同じ EC2 で配布が実行中です。終わるのを待ってから再実行します |
| `理由: integrity check failed` | 配布中に版の中身が変わった可能性があります。版を公開し直していないか確かめ、再実行します |
| `衝突: <パス>` | 受講者がそのファイルを書き換えたため、上書きしていません。受講者と相談します |
| 受講者が導入用の URL で取得できない | URL の期限が切れています。手順 1.4 で作り直して配り直します |
| 受講者の `env update` が `現行版の情報（...）と一致しません` で止まる | 現行版の切り替え中です。少し待ってから受講者に再実行してもらいます。続く場合は手順 2.3 で現行版を切り替え直します |
| 受講者の接続やファイルの転送が途中で止まる | 認証情報の期限切れです。手順 3 で発行し直して渡します |
