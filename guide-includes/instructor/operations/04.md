## 1. 講習会の前の準備

### 1.1 設定ファイルのプロファイル名を確かめる

設定ファイル `{{CONFIG_DIR}}/gclue-ai-handson-config.yml` の `aws.profile` に、自分の AWS CLI のプロファイル名を書きます。
教材の公開と一斉配布のコマンドは、このプロファイルだけを使います（`--profile` で別のプロファイルを指定できるのは認証情報のコマンドだけです）。

```yaml
aws:
  profile: {{PROFILE_YAML}}
```

`--env-dir` を毎回書く代わりに、環境変数で設定ファイルの場所を指定することもできます。

```bash
export GCLUE_AI_HANDSON_ENV_DIR={{CONFIG_DIR_SH}}
```

### 1.2 講師用のアカウントでログインする

作業を始める前と、ログインの有効期限が切れたときに実行します。

```bash
aws sso login --profile {{PROFILE_SH}}
```

確認: 次のコマンドで、自分のアカウントの情報（`Arn` など）が表示されれば成功です。

```bash
aws sts get-caller-identity --profile {{PROFILE_SH}}
```

講師用のコマンドは、ここでログインした講師のアカウントで「払出し専用ユーザー」（スタックが作る、認証情報の発行専用の AWS の利用者）の鍵を読み出し、その利用者として動きます。
講師のアカウント自体に、受講者の認証情報を作る権限や教材を書き込む権限は要りません（[アクセス制御の仕様](<<= guide_link('staff/instructor/contracts.md') =>>)）。

### 1.3 受講者用ツールを公開する

受講者が手元の機器（PC・Jetson）で使うツール一式を、講習会用のバケットへ公開します。
受講者用ツールを更新したときも、同じコマンドで公開し直します。

**今回の必須条件:** macOS Bash 3.2 の修正 `fc6e58d` を含む `ccfd1a3` 以降の確認済みツールから公開してください。2026-10-09 の記録では配布済み旧版への更新は未実施です。以下を実行して公開・受講者側の更新を確認するまで「修正版を配布済み」と扱わないでください。

```bash
uv run gclue-ai-handson release publish --env-dir {{CONFIG_DIR_SH}} \
  --attendee-tools
```

確認: 最後に `受講者用ツールの manifest の SHA-256: ...` と表示されれば成功です。

### 1.4 導入用の URL を作る

受講者が `curl` だけで導入スクリプトを取得できる、有効期限付きの URL を作ります。

```bash
uv run gclue-ai-handson release bootstrap-url \
  --env-dir {{CONFIG_DIR_SH}}
```

確認: 1 行目に `https://` で始まる URL が表示されます。
この URL と [受講者 PC での導入手順](<<= guide_link('staff/instructor/support.md') =>>) を本人に伝えます。期限付き URL と認証ファイルのパスは共通フォームの対象外で、本人の PC で手動置換します。

- 有効期限は既定で設定の `max_session_duration_seconds`（最大 12 時間）で、これより長くはできません。短くする場合は `--expires-seconds <秒>` を付けます。
- 期限が切れたら、同じコマンドで作り直して配り直します。講習会の当日、受講者が導入する直前に作るのが確実です。
- 受講者側の手順は [受講者の手順](<<= guide_link('staff/instructor/support.md') =>>) にあります。

### 1.5 （任意）Python の運用ツールを配る

この任意手順のパッケージ版、後述の SSH ホスト・hook のパスはフォーム対象外です。`<...>` を手元で実値に置き換えてから実行します。

受講者の機器でも Python の運用ツールを使ってもらう場合だけ行います。
まず配布用のファイル（wheel）を作ります。

```bash
uv build --package gclue-ai-handson --wheel \
  --out-dir dist/handson-tools
```

作ったファイルを公開します。
`<パッケージのバージョン>` は、前のコマンドで `dist/handson-tools/` にできたファイル名のとおりに置き換えます。

```bash
WHEEL='dist/handson-tools/gclue_ai_handson-<パッケージのバージョン>-'
WHEEL+='py3-none-any.whl'

uv run gclue-ai-handson release publish --env-dir {{CONFIG_DIR_SH}} \
  --wheel "$WHEEL"
```

確認: `アップロード: ... -> s3://.../shared/tools/...` と表示されれば成功です。
受講者には、PC のターミナルで取得した wheel ファイルがあるディレクトリに移動してから、次を実行するよう伝えます。`<パッケージのバージョン>` は取得したファイル名に合わせて手動で置き換えます。

```bash
uv tool install \
  './gclue_ai_handson-<パッケージのバージョン>-py3-none-any.whl'
```

インストール後は次でコマンドのヘルプが表示されることを確認します。

```bash
gclue-ai-handson --help
```
