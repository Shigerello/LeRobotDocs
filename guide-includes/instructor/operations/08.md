## 5. 認証情報を取り消す

### 5.1 特定の受講者の認証情報を取り消す

認証情報の漏えいが疑われるときなどに、その受講者に発行済みの認証情報をすべて使えなくします。

```bash
uv run gclue-ai-handson credentials revoke \
  --env-dir {{CONFIG_DIR_SH}} --attendee {{ATTENDEE_ID}}
```

確認: `受講者 {{ATTENDEE_ID}} の <時刻> より前に発行した一時認証情報を失効させました。` と表示されれば成功です。

取り消した後に発行した認証情報は使えます。
受講者に続けてもらう場合は、手順 3 で発行し直して渡します。

### 5.2 全員の認証情報を取り消す

講習会の終了時などに、この講習会でこれまでに発行した認証情報をすべて使えなくします。

```bash
uv run gclue-ai-handson credentials revoke \
  --env-dir {{CONFIG_DIR_SH}} --all
```

確認: `講習会全体 の <時刻> より前に発行した一時認証情報を失効させました。` と表示されれば成功です。

どちらのコマンドも、`--dry-run` を付けると AWS を変更せずに内容だけを表示します。
