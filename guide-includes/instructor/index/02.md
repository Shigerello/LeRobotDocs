## コマンドの置換値

最初に [共通設定](<<= guide_link('common.md') =>>) を開き、開催 ID・受講者 ID・リージョン・プロファイル・開催設定ディレクトリ・教材の版などを入力します。`{{...}}` の値はその設定から反映されます。設定を確認してからコマンドをコピーしてください。

`{{CONFIG_DIR_SH}}` と `{{MATERIALS_DIR_SH}}` はシェル引数として引用済みの値なので、外側に引用符を追加しません。認証ファイル・期限付き URL は共通フォームの対象外です。残る `<...>` は手元で置き換え、秘密はフォームや資料に保存しません。

| 表記 | 決め方 |
| --- | --- |
| `{{CONFIG_DIR}}` | 構築担当が配った開催設定ディレクトリのパス |
| `{{EVENT_ID}}` | 設定の開催識別子。受講者の `env info` 表示と一致させる |
| `{{ATTENDEE_ID}}` | 設定の `attendees` に登録された本人の ID |
| `{{PROFILE}}` | 講師本人が SSO ログインする AWS CLI プロファイル |
| `{{RELEASE}}` | 未使用の教材リリース識別子。既存公開版は上書きしない |
| `{{MANIFEST_SHA}}` | `release build` が出す manifest の 64 桁ハッシュ |
| `{{MATERIALS_DIR}}` | 講師がレビューした教材だけのディレクトリ |
| `{{BUCKET}}`・`{{REGION}}` | 開催設定と構築担当から取得。資料に実値を保存しない |

認証ファイル・期限付き URL・講師の鍵を教材に混ぜないでください。受講者ごとに配布先を確認し、認証ファイル本文や URL を共有の進捗表に貼り付けません。
