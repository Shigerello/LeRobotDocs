## 開始条件

1. 構築担当から運用リポジトリ `ai-learning-handson-aws-infra`、その dev container の開き方、開催設定、講師用 SSO プロファイル、受講者 ID の一覧を受け取ります。
2. 運用リポジトリは修正 `fc6e58d` を含む確認済み版を使います。本資料の参照先は `feature/20261008_docs_updates` の `ccfd1a3` です。構築担当に `git rev-parse HEAD` の結果と修正の包含を確認してもらいます。未マージなので main にあるとは限りません。
3. dev container 内の運用リポジトリ直下で `uv sync` を済ませ、`uv run gclue-ai-handson --help` で `release`、`credentials`、`rollout` が出ることを確認します。運用環境には AWS CLI v2 と Session Manager プラグインが必要です。
4. 開催設定の `aws.profile` を自分のプロファイル名に合わせます。SSO のログインは本人が行います。構築担当から、対象 EC2 が起動済み・SSM 接続可能・受講者との対応が正しいことを確認します。

本資料はコマンド実行に必要な運用リポジトリを同梱しません。未取得なら構築担当から組織内の取得先を受け取ってください。LeRobotDocs 内で運用 CLI を実行しても環境は作成されません。
