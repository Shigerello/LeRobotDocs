## S3 の画面案内

まず受講者 PC で次を実行し、本人としてサインインします。

```bash
gclue-ai-handson-attendee console-url --open
```
EC2 と Systems Manager のコンソール表示は実測済みです。S3 のバケット一覧は権限エラーになり得ます。次のテンプレートの値を開催設定で置き換え、本人の S3 バケットパスを直接開きます（期限付きの認証 URL ではなく画面の行き先です）。

```text
https://s3.console.aws.amazon.com/s3/buckets/{{BUCKET}}?region={{REGION}}&prefix={{ATTENDEE_ID}}%2F&showversions=false
https://s3.console.aws.amazon.com/s3/buckets/{{BUCKET}}?region={{REGION}}&prefix=shared%2F&showversions=false
```

本人のS3 バケットパス・共有教材のS3 バケットパスを開くところまで実測済みです。コンソールでのダウンロード・書込み・削除は未検証です。授業の保存・回収は検証済みの CLI 経路を使います。発行されるサインイン用 URL は本人以外に共有しません。
