## 保存の小さな練習

PC で既存の作業と混ざらない空のディレクトリに入り、実行します。

```bash
printf 'workshop save check\n' > save-check.txt
gclue-ai-handson-attendee files upload ./save-check.txt --to checks
gclue-ai-handson-attendee files pull --own --prefix checks \
  --dest ./retrieved-checks
cmp ./save-check.txt ./retrieved-checks/save-check.txt
```

`cmp` が何も表示せず終了コード 0 なら内容一致です。本人のS3 バケットパス内の `checks/save-check.txt` を使うため、同名ファイルがない練習場所で行います。これは保存機能の確認であり、終了時の全成果回収を済ませたことにはなりません。
