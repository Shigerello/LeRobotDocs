## 到達点の順番

| 段階 | 本人の操作・確認 | 次へ進む条件 |
| --- | --- | --- |
| 認証 | `env info` | 本人の ID と期限が正しい |
| シェル | `gclue-ai-handson-attendee shell` | EC2 のプロンプト。終了は `exit` |
| SSH | `gclue-ai-handson-attendee ssh` | EC2 へ接続し、終了できる |
| DCV | `gclue-ai-handson-attendee dcv` | 表示されたローカル URL でデスクトップにログイン |
| 教材 | `gclue-ai-handson-attendee files pull --dest ./materials-check` | 講師が案内した版と manifest の検証が成功 |
| 保存 | 下の試験データ往復 | 取得ファイルと元の内容が一致 |

### シェル・SSH・DCV・教材取得のコマンド

受講者 PC で `activate` を読み込んだターミナルを使います。接続はひとつずつ確認します。

```bash
gclue-ai-handson-attendee shell
```

EC2 のプロンプトが出たら、そこで次を実行して PC に戻ります。

```bash
exit
```

次に PC で SSH を確認します。確認後は同じく `exit` で戻ります。

```bash
gclue-ai-handson-attendee ssh
```

DCV は次のコマンドを実行し、表示された URL をブラウザで開きます。初回は後述のパスワード設定を先に済ませます。

```bash
gclue-ai-handson-attendee dcv
```

教材の取得は別の PC ターミナルで行います。

```bash
source ~/gclue-ai-handson/{{EVENT_ID}}/activate
gclue-ai-handson-attendee files pull --dest ./materials-check
```

SSM shell のログインユーザーは `ssm-user`、SSH と DCV は `ubuntu` です。SSM shell から LeRobot の作業へ進む場合は、EC2 内で次を実行して切り替えます。

```bash
sudo -iu ubuntu
```

DCV 初回パスワードは EC2 シェルで次を実行し、本人が入力して設定します。

```bash
sudo /var/lib/handson/bin/handson-dcv-password set
```

ポート転送のターミナルは開いたままにします。ログイン後の灰色画面は一度ログアウトしてログインし直すと改善した実績があります。GNOME に SIGQUIT を送らないでください。文字が乱れる場合は GNOME Terminal のフォントを Monospace 12、セル幅・高さを 1.00 にします。
